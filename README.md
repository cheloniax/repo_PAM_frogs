## Data and code for: Hoefer S, Allen-Ankins S, McKnight DT, Nordberg EJ, Schwarzkopf L (2026) Passive acoustic monitoring outperforms observer-based methods for Australian frog communities.

### Contains:

- **/data**: data used in the analyses.
    - frog_data.csv: main dataset containing individual detection of each frog species for each survey plot at each site.
    - frogs_PAM_daily_all.csv: dataset containing validation of 115 example calls for 50 species of Australian frogs.
    - frog_data_season.csv: dataset containing seasonal detections of frogs via PAM.
    - expenses_daily.csv: dataset containing expenses of OBM and PAM broken down by day.
    - ReadMeDataFiles.txt: meta-data describing the contents and structure of frog_data.csv, frogs_PAM_daily_all.csv, frog_data_season.csv, and expenses_daily.csv.
- **/scripts**: R code in qmd format.
    - R_code_biodiversityFrogs.qmd: R code used for all data processing, visualisation, and analyses.
- **/supplemantary**: Supplemantary tables and figures.
    - supporting_information.pdf: Supplementary figures S1-S4 and tables S1-S5.
